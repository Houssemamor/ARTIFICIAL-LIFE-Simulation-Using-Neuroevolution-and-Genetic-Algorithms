Raw experiment data: runs and families
What do EXP-* names mean?

EXP-* is the folder name of one experiment run under experiments/. Each folder holds a summary JSON, optionally SVG plots, and sometimes .npz controller weights. The part after EXP- is the family: the question that run was built to answer. Here EXP-GEN tests generalization, EXP-D tests fitness weighting, EXP-E tests crossover, EXP-COEV covers predator and prey, EXP-NEAT covers network structure, and EXP-TENSOR covers the tensor ecosystem.

Family in the table comes from that prefix. Seeds is the number of independent repeats of the same condition. Plots lists charts embedded in this page. Open shows the recorded generations.
